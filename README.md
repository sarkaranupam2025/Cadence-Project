# Cadence

Cadence turns live design-operations data into traceable monthly, quarterly, and yearly playbacks. This prototype follows the supplied Power HMC reference, uses an IBM Carbon-inspired visual system, and includes report management, KPI drill-downs, version scope, metric definitions, source health, audit history, and presentation mode.

## Run locally

```sh
npm install
npm run dev
```

## Deploy

The repository is configured as a Cloudflare Worker with static assets.

```sh
npm run deploy
```
